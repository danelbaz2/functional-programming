Architecture

Pure logic, separated from I/O

Five packages, each with one job. Purity is enforced by convention and checked by the test suite: nothing in core touches a disk, a network, or standard out.

com.hit.fp.model
pure
Immutable case classes and the OrderSize algebraic data type.
com.hit.fp.core
pure
Parsing, analytics, data generation, report rendering, the custom combinator.
com.hit.fp.spark
pure transforms
How the core functions get distributed across a Spark session.
com.hit.fp.io
effects
The only code allowed to read a file, write a file, or print.
com.hit.fp.Main
effects
The impure shell that wires the whole run together.
pure core, tested without Spark

Setup

Run it locally

Install these yourself — they're not part of the repository.

JDK 11

The project SDK, required by the course.

JDK 17+

sbt 2.0.6 needs it just to start the build tool; the project still targets JDK 11.

IntelliJ IDEA

With the Scala plugin installed.

# generates the dataset if missing, then runs the pipeline
sbt run

# runs the ScalaTest suites
sbt test

In IntelliJ: open the folder as an sbt project, set the SDK to JDK 11, and run com.hit.fp.Main. Generated input goes to data/, reports go to output/ — the fixed seed in PipelineConfig.default makes the dataset identical on every machine.

🪟
Running on Windows

Spark reaches the disk through Hadoop's filesystem layer, which needs a native helper for Windows-style file permissions. Download winutils.exe and hadoop.dll for Hadoop 3.3.x, point HADOOP_HOME at the folder containing them, add it to PATH, then restart IntelliJ. Linux and macOS need none of this.
